# O que é?

**emptyxz** é uma CLI para criar projetos **Next.js + TypeScript** com uma base limpa, moderna e pronta para produção.

Em vez de começar do zero e repetir a mesma configuração toda vez, basta executar:

```bash
npx emptyxz init
```

E começar a desenvolver.

> **Menos configuração. Mais desenvolvimento.**

---

## ✦ Por que emptyxz?

Criar um projeto Next.js é fácil.

Criar uma **boa base inicial** nem sempre.

O emptyxz elimina a configuração inicial repetitiva e fornece uma fundação simples e limpa, fácil de evoluir.

### ⚡ Rápido

Crie um projeto em segundos.

### 🔷 TypeScript

TypeScript desde o primeiro arquivo.

### 🧱 Estrutura limpa

Uma base simples, sem abstrações desnecessárias.

### 🧹 Minimalista

Sem dezenas de dependências que você talvez nunca use.

### 🚫 Sem `AGENTS.md`

O projeto gerado não inclui arquivos ou configurações específicos para agentes de IA.

### 🎯 Seu projeto, suas decisões

O emptyxz não tenta ditar toda a arquitetura do seu projeto.

Ele fornece apenas o ponto de partida.

---

## 🚀 Começando

Execute:

```bash
npx emptyxz init
```

Entre no projeto:

```bash
cd seu-projeto
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Sua aplicação estará disponível em:

```text
http://localhost:3000
```

## 📦 O que está incluído?

O emptyxz começa com o essencial:

* Next.js
* React
* TypeScript
* App Router
* ESLint
* CSS
* Estrutura inicial limpa
* Configuração moderna
* Sem `AGENTS.md`

### Estrutura

```text
seu-projeto/

│
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
│
├── public/
│
├── package.json
├── tsconfig.json
├── next.config.ts
└── eslint.config.mjs
```

A estrutura é intencionalmente simples.

Conforme seu projeto crescer, adicione as ferramentas e abstrações que realmente fizerem sentido para sua aplicação.

## 🧠 Filosofia

### Comece vazio. Construa qualquer coisa.
