# What is it?

**emptyxz** is a CLI for creating **Next.js + TypeScript** projects with a clean, modern and production-ready starting point.

Instead of starting from scratch and repeating the same setup every time, simply run:

```bash
npx emptyxz init
```

And start building.

> **Less setup. More building.**

---

## ✦ Why emptyxz?

Creating a Next.js project is easy.

Creating a **good starting point** isn't always.

emptyxz removes the repetitive initial setup and gives you a simple, clean foundation that's easy to evolve.

### ⚡ Fast

Create a project in seconds.

### 🔷 TypeScript

TypeScript from the very first file.

### 🧱 Clean structure

A simple foundation without unnecessary abstractions.

### 🧹 Minimal

No dozens of dependencies you may never use.

### 🚫 No `AGENTS.md`

The generated project doesn't include AI-agent-specific files or configuration.

### 🎯 Your project, your decisions

emptyxz doesn't try to dictate your entire architecture.

It gives you the starting point.

---

## 🚀 Getting Started

Run:

```bash
npx emptyxz init
```

Enter your project:

```bash
cd your-project
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Your application will be available at:

```text
http://localhost:3000
```

---

## 📦 What's included?

emptyxz starts with the essentials:

* Next.js
* React
* TypeScript
* App Router
* ESLint
* CSS
* Clean initial structure
* Modern configuration
* No `AGENTS.md`

### Structure

```text
your-project/
│
├── app/
│   ├── layout.tsx
│   ├── page.tsx
│   └── globals.css
│
├── public/
│
├── package.json
├── tsconfig.json
├── next.config.ts
└── eslint.config.mjs
```

The structure is intentionally simple.

As your project grows, add the tools and abstractions that actually make sense for your application.
